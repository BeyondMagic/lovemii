## Context

<span style="color: #666666">Provide context for what this feature is about, the motivation behind it, and the goal it aims to achieve.</span>

I am using [Tailscale](https://tailscale.com/) to connect to my home network and access my services remotely. However, I don't need to have these services running all the time, just when I need them. I want to be able to start and stop these services easily, without having to SSH into my home server and run commands manually.

Although eventually I want to have this on my phone, this feature is primarily for my laptop, where I can easily start and stop services with a single click or command. This will save me time and effort, and make it easier to manage my home server.
